# Poker Face

A webcam-only stream overlay game built on the Presage SmartSpectra SDK. The streamer tries to keep a straight face; the audience tries to break it.

Work in progress. Setup, demo, and Consent and Data Handling sections will be written before submission.

## Development

```
yarn install
cp .env.example .env   # add SMARTSPECTRA_API_KEY
yarn spike             # signal latency/stability probe
```
